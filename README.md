# 天神屋 SNS投稿用 画像置き場

InstagramとX（旧Twitter）の投稿で使う画像を置いています。
GitHub Pages で配信していて、BufferとXがここのURLから画像を取得します。

## URLの形

```
https://khoriguchi54.github.io/tenjinya-sns-assets/ig/<年月>/<年月>_NN.jpg
例) https://khoriguchi54.github.io/tenjinya-sns-assets/ig/202609/202609_01.jpg
```

## 置き方

`プログラム/upload_ig_images_git.sh` を使います。手順は共有フォルダの
`マニュアル/02_Instagram自動投稿/運用仕様書.md` ステップ4を参照してください。

## なぜ公開リポジトリなのか

GitHub Pages を無料プランで使うには公開リポジトリである必要があるためです。
ここに置く画像はもともとSNSで公開するものです。
**画像以外のファイル（原稿・認証情報・スプレッドシート等）は置かないでください。**
